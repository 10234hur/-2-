# DNA 복제 돌연변이 시뮬레이션

세포가 DNA를 복제할 때 생기는 복제 오류가 3단계 검증을 거쳐 돌연변이가 되는 과정을 확률로 실험하는 파이썬 프로그램입니다. 통합과학 탐구 보고서 "무성 생식과 유성 생식의 돌연변이 발생 요인"에서 정리한 내용을 직접 확인해 보려고 만들었습니다.

## 배경

DNA를 복제할 때는 아주 낮은 확률로 잘못된 염기가 끼어듭니다. 세포는 이 오류를 세 단계로 걸러냅니다.

| 단계 | 내용 | 확률 |
|---|---|---|
| 1단계 | 염기 선택 중 오류 발생 | 약 10⁻⁵ |
| 2단계 | 오류가 즉시 교정(proofreading)을 통과 | 약 10⁻² |
| 3단계 | 오류가 불일치 복구(mismatch repair)를 통과 | 약 10⁻³ |

세 단계를 모두 통과한 오류만 돌연변이로 확정되므로, 각 단계를 독립사건으로 보면 확률의 곱셈정리로

P = 10⁻⁵ × 10⁻² × 10⁻³ = 10⁻¹⁰

이 됩니다. 또 염기 n개를 복제할 때 돌연변이 기댓값은 E(X) = n·P 입니다. 위 확률은 문헌의 대략적인 값이며 생물과 조건에 따라 다릅니다.

## 실험

1. **검증 시스템의 효과**: 즉시 교정과 불일치 복구를 켜고 끄며 돌연변이 수를 비교합니다.
2. **돌연변이원의 효과**: 자외선 같은 돌연변이원에 노출되어 1단계 오류 확률이 ×1, ×10, ×100, ×1000이 되는 경우를 비교합니다.
3. **표본 크기의 효과**: 세포 수가 늘수록 세포당 평균 돌연변이 수가 기댓값에 가까워지는지 확인합니다.

## 실행 방법

```bash
pip install -r requirements.txt
python simulation.py
```

실행하면 결과가 터미널에 출력되고, 그래프가 `results.png`로 저장됩니다. 그래프의 한글이 깨지면 `NanumGothic` 같은 한글 글꼴을 설치하세요.

## 구현 설명

- 염기 하나하나를 모두 돌리면 너무 느리기 때문에, "n번 시행 중 성공 횟수"를 뽑는 이항분포 방식으로 각 단계의 개수를 계산합니다.
- 기댓값이 작을 때는 성공 사이의 간격을 건너뛰며 정확하게 세고, 기댓값이 아주 클 때는 정규분포 근사를 사용합니다.
- 각 단계는 서로 독립이라고 단순화했습니다. 실제 세포에서는 완전히 독립적이지 않을 수 있습니다.
- 돌연변이는 위치와 상관없이 균일하게 생긴다고 가정했습니다.
